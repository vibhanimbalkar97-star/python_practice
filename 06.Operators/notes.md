# Python Operators — Complete Beginner-Friendly Interview Revision Notes

An operator is a symbol or keyword that performs an operation on values.

```
a = 10
b = 3
print(a + b)  # 13
```

- `a` and `b` are operands (the values being used).
- `+` is the operator.
- `13` is the result.

Python operators are grouped into these categories:

\| Category | Operators |\
\|---|---|\
\| Arithmetic | `+`, `-`, `*`, `/`, `//`, `%`, `**` |\
\| Comparison / Relational | `==`, `!=`, `>`, `<`, `>=`, `<=` |\
\| Assignment | `=`, `+=`, `-=`, `*=`, `/=`, etc. |\
\| Logical | `and`, `or`, `not` |\
\| Identity | `is`, `is not` |\
\| Membership | `in`, `not in` |\
\| Bitwise | `&`, `|`, `^`, `~`, `<<`, `>>` |\
\| Conditional expression | `x if condition else y` |\
\| Special operators / concepts | `:=`, operator precedence, associativity |

Let's cover each one with examples, outputs, and rules.
