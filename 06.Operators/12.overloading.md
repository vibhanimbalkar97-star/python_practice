# 12. Operator Overloading

Python operators can behave differently depending on the data type.

For example, `+`:

```
print(5 + 3)             # 8
print("Hi" + " there")   # Hi there
print([1, 2] + [3, 4])   # [1, 2, 3, 4]
```

The operator is the same, but the behavior depends on the operands.

This is called operator overloading.

### Common examples

| Operator | Number behavior   | Other behavior                                        |
| -------- | ----------------- | ----------------------------------------------------- |
| `+`      | Addition          | Joins strings or lists                                |
| `*`      | Multiplication    | Repeats strings or lists                              |
| `==`     | Compares values   | Can be customized for objects                         |
| `in`     | Checks membership | Works with strings, lists, tuples, sets, dictionaries |

### Why does `"Hi" * 3` work?

```
print("Hi" * 3)
```

Output:

```
HiHiHi
```

Python defines repetition for strings and sequences.

But this is invalid:

```
print("Hi" * 2.5)
```

Output:

```
TypeError
```

Strings can be repeated using an integer count, not a float.
