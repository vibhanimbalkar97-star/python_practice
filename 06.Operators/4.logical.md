# 4. Logical Operators

Logical operators are used with conditions.

Python has three logical operators:

- `and`
- `or`
- `not`

## Basic truth table

| A       | B       | `A and B` | `A or B` |
| ------- | ------- | --------- | -------- |
| `True`  | `True`  | `True`    | `True`   |
| `True`  | `False` | `False`   | `True`   |
| `False` | `True`  | `False`   | `True`   |
| `False` | `False` | `False`   | `False`  |

### Rule 1: `and` requires both conditions to be true

```
age = 25
print(age > 18 and age < 60)
```

Output:

```
True
```

Both conditions are true.

### Rule 2: `or` requires at least one condition to be true

```
age = 15
print(age < 18 or age > 60)
```

Output:

```
True
```

The first condition is true.

### Rule 3: `not` reverses Boolean value

```
print(not True)   # False
print(not False)  # True
```

### Rule 4: Python's `and` and `or` return operands, not always Boolean values

This is a very common interview topic.

```
print(5 and 10)
print(0 and 10)
print(5 or 10)
print(0 or 10)
```

Output:

```
100510
```

Why?

- `and` returns the first falsy value. If all values are truthy, it returns the last value.
- `or` returns the first truthy value. If all values are falsy, it returns the last value.

### Truthy and falsy values

| Falsy value | Example                 |
| ----------- | ----------------------- |
| `False`     | `bool(False)` → `False` |
| `0`         | `bool(0)` → `False`     |
| `0.0`       | `bool(0.0)` → `False`   |
| `""`        | `bool("")` → `False`    |
| `[]`        | `bool([])` → `False`    |
| `()`        | `bool(())` → `False`    |
| `{}`        | `bool({})` → `False`    |
| `set()`     | `bool(set())` → `False` |
| `None`      | `bool(None)` → `False`  |

Other values are generally truthy:

```
print(bool("False"))  # True
print(bool("0"))      # True
print(bool([0]))      # True
print(bool(" "))      # True
```

Why? They are non-empty values. Python does not interpret the text `"False"` as the Boolean value `False`.

### Rule 5: Short-circuit evaluation

Python may skip evaluating the second operand.

```
print(False and 10 / 0)
```

Output:

```
False
```

No `ZeroDivisionError` occurs because `and` already knows the result is false.

```
print(True or 10 / 0)
```

Output:

```
True
```

No error occurs because `or` already knows the result is true.

Interview note: `and` and `or` short-circuit from left to right.
