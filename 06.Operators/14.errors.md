# 14. Common Operator Errors

| Code           | Error               | Why                                 |
| -------------- | ------------------- | ----------------------------------- |
| `"5" + 2`      | `TypeError`         | Cannot add string and integer       |
| `"5" - 2`      | `TypeError`         | Cannot subtract integer from string |
| `10 / 0`       | `ZeroDivisionError` | Cannot divide by zero               |
| `10 // 0`      | `ZeroDivisionError` | Floor division by zero              |
| `10 % 0`       | `ZeroDivisionError` | Modulus by zero                     |
| `[1, 2] - [1]` | `TypeError`         | Lists do not support subtraction    |
| `5 & 2.5`      | `TypeError`         | Bitwise operation expects integers  |
| `None + 1`     | `TypeError`         | `None` is not numeric               |
| `5 in 10`      | `TypeError`         | Integer is not iterable             |
| `5 < 3 + "2"`  | `TypeError`         | Cannot add integer and string       |
