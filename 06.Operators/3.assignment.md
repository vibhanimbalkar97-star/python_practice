# 3. Assignment Operators

Assignment operators store or update a value in a variable.

## Basic assignment

```
x = 10
```

`=` assigns the value `10` to `x`.

## Compound assignment operators

| Operator | Example    | Equivalent to | Result if `x = 10` |
| -------- | ---------- | ------------- | ------------------ |
| `=`      | `x = 5`    | Assign        | `5`                |
| `+=`     | `x += 3`   | `x = x + 3`   | `13`               |
| `-=`     | `x -= 3`   | `x = x - 3`   | `7`                |
| `*=`     | `x *= 3`   | `x = x * 3`   | `30`               |
| `/=`     | `x /= 3`   | `x = x / 3`   | `3.333...`         |
| `//=`    | `x //= 3`  | `x = x // 3`  | `3`                |
| `%=`     | `x %= 3`   | `x = x % 3`   | `1`                |
| `**=`    | `x **= 3`  | `x = x ** 3`  | `1000`             |
| `&=`     | `x &= 3`   | `x = x & 3`   | Bitwise AND        |
| `\\|=`   | `x \\|= 3` | `x = x \\| 3` | Bitwise OR         |
| `^=`     | `x ^= 3`   | `x = x ^ 3`   | Bitwise XOR        |
| `>>=`    | `x >>= 1`  | `x = x >> 1`  | Right shift        |
| `<<=`    | `x <<= 1`  | `x = x << 1`  | Left shift         |

### Rule 1: Compound assignment updates the variable

```
x = 5x += 2print(x)  # 7
```

### Rule 2: Assignment does not return a value in Python

```
if x = 5:    print("Hi")
```

This causes a `SyntaxError`.

To assign inside an expression, Python has the special walrus operator `:=`, explained later.

### Rule 3: Compound assignment may mutate a mutable object

```
a = [1, 2]
a += [3]
print(a)  # [1, 2, 3]
```

For a list, `+=` updates the list in place.

Compare:

```
a = [1, 2]
a = a + [3]
```

This creates a new list and assigns it to `a`.

For simple numbers, `x += 2` behaves like `x = x + 2`.
