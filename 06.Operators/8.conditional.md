# 8. Conditional Expression — Ternary Operator

Python has a one-line conditional expression.

### Syntax

```
value_if_true if condition else value_if_false
```

Example:

```
age = 20
result = "Adult" if age >= 18 else "Minor"
print(result)
```

Output:

```
Adult
```

### Rule 1: Condition is checked first

```
x = 5
result = "Positive" if x > 0 else "Not positive"
print(result)  # Positive
```

### Rule 2: Only the selected expression is evaluated

```
x = 5
result = 10 if x > 0 else 1 / 0
print(result)  # 10
```

No `ZeroDivisionError` occurs because the `else` expression is not selected.

### Rule 3: You can nest conditional expressions, but keep them readable

```
x = 0
result = "Positive" if x > 0 else "Negative" if x < 0 else "Zero"
print(result)  # Zero
```

For beginners, regular `if/elif/else` is usually easier to read.
