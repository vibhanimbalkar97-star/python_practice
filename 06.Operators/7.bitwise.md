# 7. Bitwise Operators

Bitwise operators work on the binary bits of integers.

First, understand binary:

| Decimal | Binary |
| ------- | ------ |
| `0`     | `000`  |
| `1`     | `001`  |
| `2`     | `010`  |
| `3`     | `011`  |
| `4`     | `100`  |
| `5`     | `101`  |
| `6`     | `110`  |
| `7`     | `111`  |

## Bitwise operators table

| Operator | Name             | Example   | Output |
| -------- | ---------------- | --------- | ------ |
| `&`      | AND              | `5 & 3`   | `1`    |
| `\\|`    | OR               | `5 \\| 3` | `7`    |
| `^`      | XOR              | `5 ^ 3`   | `6`    |
| `~`      | NOT / complement | `~5`      | `-6`   |
| `<<`     | Left shift       | `5 << 1`  | `10`   |
| `>>`     | Right shift      | `5 >> 1`  | `2`    |

### Rule 1: Bitwise AND `&`

A bit is `1` only when both bits are `1`.

```
a = 5  # 101b = 3  # 011
print(a & b)
```

Output:

```
001 = 1
```

### Rule 2: Bitwise OR `|`

A bit is `1` when at least one bit is `1`.

```
print(5 | 3)
```

```
101
011
---
111 = 7
```

### Rule 3: Bitwise XOR `^`

A bit is `1` when the bits are different.

```
print(5 ^ 3)
```

```
101
011
---
110 = 6
```

### Rule 4: Bitwise NOT `~`

Python uses this identity for integers:

\\[ \sim x = -x - 1 \\]

```
print(~5)   # -6
print(~0)   # -1
print(~10)  # -11
```

Why is `~5` equal to `-6`?

Because:

\\[ -5 - 1 = -6 \\]

### Rule 5: Left shift `<<`

Moves bits left. For positive integers, shifting left by one position is equivalent to multiplying by 2.

```
print(5 << 1)  # 10
print(5 << 2)  # 20
```

```
5 = 101
101 << 1 = 1010 = 10
```

### Rule 6: Right shift `>>`

Moves bits right. For positive integers, shifting right by one position is equivalent to floor division by 2.

```
print(5 >> 1)  # 2
print(5 >> 2)  # 1
```

```
5 = 101
101 >> 1 = 10 = 2
```

### Bitwise interview checklist

- `&` → both bits must be `1`.
- `|` → either bit can be `1`.
- `^` → bits must be different.
- `~x` → `-x - 1`.
- `x << 1` → multiply by 2 for positive integers.
- `x >> 1` → floor divide by 2 for positive integers.
- Bitwise operators work on integers; using floats generally causes `TypeError`.
