# 2. Comparison Operators

Comparison operators compare two values. The result is always `True` or `False`.

| Operator | Meaning               | Example  | Output  |
| -------- | --------------------- | -------- | ------- |
| `==`     | Equal to              | `5 == 5` | `True`  |
| `!=`     | Not equal to          | `5 != 3` | `True`  |
| `>`      | Greater than          | `5 > 3`  | `True`  |
| `<`      | Less than             | `5 < 3`  | `False` |
| `>=`     | Greater than or equal | `5 >= 5` | `True`  |
| `<=`     | Less than or equal    | `3 <= 5` | `True`  |

## Rule 1: `==` compares values

```
a = 5b = 5print(a == b)  # True
```

## Rule 2: `=` and `==` are different

```
a = 10       # Assigns value
print(a == 10)  # Checks equality
```

- `=` assigns a value.
- `==` checks whether values are equal.

## Rule 3: Numeric types can compare equal

```
print(5 == 5.0)  # True
print(True == 1) # True
print(False == 0) # True
```

Python considers these numeric values equal, even though their types differ.

## Rule 4: Strings compare lexicographically

```
print("apple" < "banana")  # True
print("20" > "100")        # True
```

Strings compare character by character using Unicode values.

```
print("A" < "a")  # True
```

Uppercase `"A"` has a lower Unicode value than lowercase `"a"`.

## Rule 5: Chained comparisons are allowed

```
x = 5print(1 < x < 10)  # True
```

This is equivalent to:

```
print(1 < x and x < 10)
```

Python checks both comparisons.
