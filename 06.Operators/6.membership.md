# 6. Membership Operators

Membership operators check whether an item exists inside a collection or sequence.

| Operator | Meaning             |
| -------- | ------------------- |
| `in`     | Item exists         |
| `not in` | Item does not exist |

### Rule 1: Membership in a string

```
print("a" in "apple")      # True
print("z" in "apple")      # False
print("app" in "apple")    # True
```

String membership is case-sensitive:

```
print("A" in "apple")  # False
```

### Rule 2: Membership in a list

```
numbers = [10, 20, 30]
print(20 in numbers)      # True
print(40 not in numbers)  # True
```

### Rule 3: Membership in a dictionary checks keys

```
student = {"name": "Asha", "age": 20}
print("name" in student)  # True
print("Asha" in student)  # False
print(20 in student)      # False
```

To check values:

```
print("Asha" in student.values())  # True
```

### Rule 4: Membership in a set

```
numbers = {1, 2, 3}
print(2 in numbers)  # True
print(5 in numbers)  # False
```

### Rule 5: Membership checks elements, not partial numeric relationships

```
numbers = [10, 20, 30]
print(15 in numbers)  # False
```

`15` is not an element of the list, even though it is between `10` and `20`.
