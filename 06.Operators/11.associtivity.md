# 11. Associativity — When Operators Have the Same Precedence

Associativity tells Python which direction to evaluate operators when they have equal precedence.

| Direction     | Operators / example | Result |
| ------------- | ------------------- | ------ |
| Left to right | `10 - 3 - 2`        | `5`    |
| Left to right | `10 / 2 * 3`        | `15.0` |
| Right to left | `2 ** 3 ** 2`       | `512`  |

### Example: left to right

```
print(10 - 3 - 2)
```

Output:

```
5
```

It means:

```
(10 - 3) - 2
```

### Example: right to left

```
print(2 ** 3 ** 2)
```

Output:

```
512
```

It means:

```
2 ** (3 ** 2)
```

Note: Comparisons can be chained:

```
print(1 < 5 < 10)  # True
```

This is not the same as ordinary left-to-right arithmetic.
