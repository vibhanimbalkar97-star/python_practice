# 5. Identity Operators

Identity operators check whether two variables refer to the same object in memory.

| Operator | Meaning             |
| -------- | ------------------- |
| `is`     | Same object         |
| `is not` | Not the same object |

### Rule 1: `==` checks value; `is` checks identity

```
a = [1, 2]
b = [1, 2]
print(a == b)  # True
print(a is b)  # False
```

Why?

Both lists contain the same values, so `==` is true. But they are two separate list objects, so `is` is false.

### Rule 2: One variable assigned to another refers to the same object

```
a = [1, 2]
b = a
print(a == b)  # True
print(a is b)  # True
```

Both names refer to the same list.

```
b.append(3)
print(a)  # [1, 2, 3]
```

Changing the list through `b` also affects what `a` sees.

### Rule 3: Use `is` for `None`

```
value = None
print(value is None)  # True
```

Preferred:

```
if value is None:    
print("No value")
```

Avoid using `value == None` when checking for `None`.

### Important caution

```
a = 1000b = 1000
print(a == b)  # True
print(a is b)  # May depend on implementation details
```

Python may reuse some objects internally. Do not use `is` to compare numbers or strings for equality.

Revision rule:

- `==` → values equal?
- `is` → same object?
- `is None` → recommended check for `None`.
