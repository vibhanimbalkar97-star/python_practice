# 10. Operator Precedence

Precedence means which operator is evaluated first.

For example:

```
print(2 + 3 * 4)
```

Output:

```
14
```

Why? Multiplication has higher precedence than addition.

```
3 * 4 = 12
2 + 12 = 14
```

## Precedence table — high to low

| Priority               | Operators / expressions                                 | Example                     |
| ---------------------- | ------------------------------------------------------- | --------------------------- |
| Highest                | Parentheses, indexing, function calls, attribute access | `(2 + 3)`, `a[0]`, `func()` |
| High                   | `**`                                                    | `2 ** 3`                    |
| Unary                  | `+x`, `-x`, `~x`                                        | `-5`                        |
| Multiplication group   | `*`, `/`, `//`, `%`, `@`                                | `5 * 2`                     |
| Addition group         | `+`, `-`                                                | `5 + 2`                     |
| Shifts                 | `<<`, `>>`                                              | `5 << 1`                    |
| Bitwise AND            | `&`                                                     | `5 & 3`                     |
| Bitwise XOR            | `^`                                                     | `5 ^ 3`                     |
| Bitwise OR             | `\\|`                                                   | `5 \\| 3`                   |
| Comparisons            | `<`, `<=`, `>`, `>=`, `==`, `!=`, `in`, `is`            | `5 > 3`                     |
| Logical NOT            | `not`                                                   | `not True`                  |
| Logical AND            | `and`                                                   | `True and False`            |
| Logical OR             | `or`                                                    | `True or False`             |
| Conditional expression | `if ... else`                                           | `"A" if x else "B"`         |
| Lowest                 | `lambda`, assignment expression `:=`                    | `lambda x: x`, `(n := 5)`   |

### Rule 1: Parentheses change the order

```
print((2 + 3) * 4)  # 20
print(2 + 3 * 4)    # 14
```

### Rule 2: Multiplication before addition

```
print(10 + 2 * 3)  # 16
```

### Rule 3: `not` has lower precedence than comparisons

```
print(not 5 == 5)
```

Output:

```
False
```

It means:

```
print(not (5 == 5))
```

### Rule 4: `and` has higher precedence than `or`

```
print(True or False and False)
```

Output:

```
True
```

Equivalent:

```
print(True or (False and False))
```

### Rule 5: Exponentiation associates right to left

```
print(2 ** 3 ** 2)
```

Output:

```
512
```

It means:

```
print(2 ** (3 ** 2))
```

Because `3 ** 2 = 9`, then `2 ** 9 = 512`.

### Rule 6: Parentheses are the safest way to clarify

```
result = (a + b) * c
```

Use parentheses whenever the expression is confusing, even if you know precedence.
