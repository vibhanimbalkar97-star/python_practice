# 13. Important Data Type Rules Related to Operators

These rules are frequently tested with operator questions.

## Rule 1: Boolean values behave like integers in arithmetic

```
print(True + True)    # 2
print(True + 5)       # 6
print(False + 5)      # 5
print(True * 10)      # 10
```

Why?

```
True  == 1False == 0
```

But:

```
print(type(True))  # <class 'bool'>
```

`bool` is a subclass of `int`, so Boolean values can be used in numeric operations.

## Rule 2: Strings cannot be added to numbers directly

```
print("10" + 5)
```

Output:

```
TypeError
```

Convert explicitly:

```
print(int("10") + 5)  # 15
print("10" + str(5))  # 105
```

## Rule 3: `None` cannot be used in normal arithmetic

```
print(None + 5)
```

Output:

```
TypeError
```

You must handle `None` or convert it appropriately before arithmetic.

## Rule 4: Division by zero causes an error

```
print(10 / 0)
```

Output:

```
ZeroDivisionError
```

This is different from JavaScript, where `10 / 0` returns `Infinity`.

## Rule 5: `int` and `float` can be mixed

```
print(5 + 2.5)  # 7.5
print(5 * 2.5)  # 12.5
print(5 / 2)    # 2.5
```

Python converts the integer to a float during mixed numeric operations.

## Rule 6: `complex` numbers support arithmetic

```
a = 2 + 3jb = 1 + 2jprint(a + b)  # (3+5j)print(a * b)  # (-4+7j)
```

But comparisons such as `<` and `>` are not supported for complex numbers:

```
print((2 + 3j) > (1 + 2j))
```

Output:

```
TypeError
```

Complex numbers can be compared for equality (`==`) but not ordered.
