# 1. Arithmetic Operators

Arithmetic operators perform mathematical operations.

## Basic arithmetic rules

| Operator | Name                | Example   | Output     | Why                             |
| -------- | ------------------- | --------- | ---------- | ------------------------------- |
| `+`      | Addition            | `10 + 3`  | `13`       | Adds values                     |
| `-`      | Subtraction         | `10 - 3`  | `7`        | Subtracts right from left       |
| `*`      | Multiplication      | `10 * 3`  | `30`       | Multiplies values               |
| `/`      | Division            | `10 / 3`  | `3.333...` | Normal division returns `float` |
| `//`     | Floor division      | `10 // 3` | `3`        | Rounds quotient down            |
| `%`      | Modulus / remainder | `10 % 3`  | `1`        | Gives remainder                 |
| `**`     | Exponentiation      | `2 ** 3`  | `8`        | Means 2 raised to power 3       |

### Rule 1: `int + int` gives an integer

```
print(5 + 2)
```

Output:

```
7
```

### Rule 2: `int + float` gives a float

```
print(5 + 2.5)
```

Output:

```
7.5
```

Python converts the integer to a float for the operation.

```
print(type(5 + 2.5))
```

Output:

```
<class 'float'>
```

### Rule 3: `/` always returns a float

```
print(10 / 2)
print(type(10 / 2))
```

Output:

```
5.0
<class 'float'>
```

Even when the division is exact, `/` returns a float.

### Rule 4: `//` means floor division, not simply removing decimals

```
print(10 // 3)  # 3
print(9 // 3)   # 3
print(7 // 2)   # 3
```

With negative numbers, it rounds down toward negative infinity:

```
print(-7 // 2)
```

Output:

```
-4
```

Why?

\\[ -7 / 2 = -3.5 \\]

Floor of `-3.5` is `-4`, not `-3`.

### Rule 5: `%` gives the remainder

```
print(10 % 3)  # 1
print(8 % 2)   # 0
print(7 % 2)   # 1
```

For Python numbers, the remainder follows the sign of the divisor:

```
print(-7 % 3)  # 2
print(7 % -3)  # -2
```

### Important relationship

For ordinary numeric values:

\\[ a = (a // b) \times b + (a \\% b) \\]

Example:

```
print(10 // 3)  # 3
print(10 % 3)   # 1
# 10 = (3 * 3) + 1
```

### Rule 6: `**` is power

```
print(2 ** 3)  # 8
print(5 ** 2)  # 25
print(9 ** 0)  # 1
```

`2 ** 3` means \\(2^3\\), or `2 * 2 * 2`.

### Rule 7: `+` and `*` also work with strings and lists

| Example          | Output         | Why                  |
| ---------------- | -------------- | -------------------- |
| `"Hi" + "Hello"` | `"HiHello"`    | String concatenation |
| `"Hi" * 3`       | `"HiHiHi"`     | Repeats string       |
| `[1, 2] + [3]`   | `[1, 2, 3]`    | Joins lists          |
| `[1, 2] * 2`     | `[1, 2, 1, 2]` | Repeats list         |

But this is not allowed:

```
print("5" + 2)
```

Output:

```
TypeError
```

Python does not automatically convert a string to a number for addition.

Use explicit conversion:

```
print(int("5") + 2)  # 7
```
