# 9. Walrus Operator `:=`

The walrus operator is called the assignment expression operator.

It assigns a value and returns that value in an expression.

```
if (n := 5) > 3:    
print(n)
```

Output:

```
5
```

### Compare `=` and `:=`

| Operator | Use                          | Example        |
| -------- | ---------------------------- | -------------- |
| `=`      | Normal assignment statement  | `x = 5`        |
| `:=`     | Assigns inside an expression | `(x := 5) > 3` |

### Example with a string

```
if (name := input("Enter name: ")):    
print("Hello", name)
```

If the user enters a non-empty name, it prints the greeting.

If the user presses Enter without typing anything, the empty string is falsy, so the greeting is skipped.

### Rules

- Use parentheses where needed.
- It is useful when a value is needed both for a condition and later in the code.
- Do not use it just to make code shorter; readability matters.
