## 7. Comparison Operators

These operators are frequently used in conditions.

| Operator | Meaning               | Example         |
| -------- | --------------------- | --------------- |
| `==`     | Equal                 | `5 == 5` → True |
| `!=`     | Not equal             | `5 != 3` → True |
| `>`      | Greater than          | `8 > 5` → True  |
| `<`      | Less than             | `3 < 5` → True  |
| `>=`     | Greater than or equal | `5 >= 5` → True |
| `<=`     | Less than or equal    | `4 <= 5` → True |

### Common Mistake: `=` vs `==`

```
x = 10
```

`=` assigns a value.

```
x == 10
```

`==` compares two values.

Wrong:

```
if x = 10:    print("Hello")
```

This causes a `SyntaxError`.

Correct:

```
if x == 10:    print("Hello")
```
