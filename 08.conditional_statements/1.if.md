## 2. `if` Statement

### Syntax

```
if condition:  
 # code executes when condition is True
```

Example:

```
marks = 80
if marks >= 35:    
print("Pass")
```

Output:

```
Pass
```

### Rules

- The condition must evaluate to `True` or `False`.
- Use a colon `:` after the condition.
- Indentation is mandatory.
- Python commonly uses 4 spaces for indentation.
- If the condition is `False`, the block is skipped.

Example:

```
marks = 20if marks >= 35:    print("Pass")print("Exam completed")
```

Output:

```
Exam completed
```

Why? The condition is False, so only the code outside the `if` block runs.
