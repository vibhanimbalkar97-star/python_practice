## 10. `match-case` Statement (Python 3.10+)

Used when checking one value against multiple possible patterns.

```
day = 2

match day:    
case 1:        
print("Monday")    
case 2:        
print("Tuesday")    
case 3:        
print("Wednesday")    
case _:        
print("Invalid day")
```

Output:

```
Tuesday
```

`case _` works like a default case.

### When to use?

Use `match-case` when comparing one value with many fixed options.

For ranges, use `if-elif-else`.
