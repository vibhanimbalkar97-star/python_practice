## 5. Nested `if` Statements

A nested `if` means an `if` statement inside another `if` statement.

Example:

```
age = 25
has_license = True

if age >= 18:    
 if has_license:        
 print("You can drive")    
 else:        
 print("License required")
 else:    
 print("You are underage")
```

Output:

```
You can drive
```

### Why use nested conditions?

Sometimes the second condition should only be checked after the first condition passes.

Example:

- First check: Is the person an adult?
- Second check: Does the person have a license?

### Trick: Read indentation carefully

```
x = 10
if x > 5:    
print("A")    
if x > 8:        
print("B")    
print("C")
```

Output:

```
A
B
C
```

`print("C")` belongs to the outer `if`, not the inner `if`.
