## 12. `input()` with Conditional Statements

Remember: `input()` returns a string.

Example:

```
age = input("Enter age: ")
if age >= 18:   
print("Adult")
```

This causes a `TypeError` because `age` is a string.

Correct:

```
age = int(input("Enter age: "))
if age >= 18:    
print("Adult")
else:    
print("Minor")
```

### Important Rule

| Input   | Conversion       |
| ------- | ---------------- |
| Integer | `int(input())`   |
| Decimal | `float(input())` |
| Text    | `input()`        |
