# 13. Tricky Rules – Interview Revision

These are important for solving output-based questions.

| Rule                                | Example                                     | Output     | Why?                          |
| ----------------------------------- | ------------------------------------------- | ---------- | ----------------------------- |
| First True condition executes       | `if 5 > 2: print("A")`                      | A          | Condition is True             |
| `elif` is skipped after True        | `if True: print("A") elif True: print("B")` | A          | Only first matching block     |
| `0` is falsy                        | `if 0: print("A") else: print("B")`         | B          | Zero is falsy                 |
| Empty string is falsy               | `if "": print("A") else: print("B")`        | B          | Empty string is falsy         |
| Non-empty string is truthy          | `if "False": print("A")`                    | A          | String is non-empty           |
| `not` reverses truth                | `if not 0: print("A")`                      | A          | `not 0` is True               |
| `and` stops at first falsy value    | `False and print("A")`                      | Nothing    | Second part isn't evaluated   |
| `or` stops at first truthy value    | `True or print("A")`                        | Nothing    | Second part isn't evaluated   |
| Nested blocks depend on indentation | Inner `if`                                  | Depends    | Scope of block is indentation |
| `==` compares values                | `5 == 5`                                    | True       | Values are equal              |
| `is` checks identity                | `a is b`                                    | Depends    | Checks same object            |
| `None` comparison                   | `x is None`                                 | True/False | Preferred None check          |
