## 8. Truthy and Falsy Values

Python does not always require an explicit Boolean condition.

Example:

```
name = ""if name:    print("Name exists")else:    print("Name is empty")
```

Output:

```
Name is empty
```

Python treats some values as `False` in conditions.

### Important Falsy Values

| Value   | Boolean result |
| ------- | -------------- |
| `False` | `False`        |
| `None`  | `False`        |
| `0`     | `False`        |
| `0.0`   | `False`        |
| `""`    | `False`        |
| `[]`    | `False`        |
| `{}`    | `False`        |
| `()`    | `False`        |
| `set()` | `False`        |

Most other values are truthy.

Examples:

```
if 10:    print("A")if "Python":    print("B")if [1, 2]:    print("C")
```

Output:

```
A
B
C
```

### Interview Trick

```
if 0:    
print("A")
elif 1:    
print("B")
else:    
print("C")
```

Output:

```
B
```

Why? `0` is falsy, but `1` is truthy.
