## 3. `if-else` Statement

Used when there are exactly two possible paths.

```
age = 16

if age >= 18:    
print("Adult")
else:    
print("Minor")
```

Output:

```
Minor
```

### Important rule

Only one block executes.

| Condition | Executed block |
| --------- | -------------- |
| `True`    | `if`           |
| `False`   | `else`         |

Example:

```
num = 7
if num % 2 == 0:    
print("Even")
else:    
print("Odd")
```

Output:

```
Odd
```

### Trick: `%` operator

The `%` operator returns the remainder.

```
10 % 2  # 0
7 % 2   # 1
```

- Remainder `0` → Even
- Remainder `1` → Odd
