## 4. `if-elif-else` Statement

Used when we have multiple conditions.

### Syntax

```
if condition1:   
# code
elif condition2:    
# code
elif condition3:    
# code
else:    
# default code
```

Example:

```
marks = 75
if marks >= 90:    
print("Grade A")
elif marks >= 75:    
print("Grade B")
elif marks >= 50:    
print("Grade C")
else:    
print("Fail")
```

Output:

```
Grade B
```

### Very Important Interview Rule: Order Matters

Python checks conditions from top to bottom.

Once a condition becomes `True`, Python executes that block and skips the remaining conditions.

Consider:

```
marks = 95
if marks >= 50:   
print("Grade C")
elif marks >= 75:    
print("Grade B")
elif marks >= 90:    
print("Grade A")
```

Output:

```
Grade C
```

Why? `marks >= 50` is already True. Python never checks the later conditions.

### Trick: Write conditions from highest to lowest

Correct:

```
if marks >= 90:    
print("A")
elif marks >= 75:   
 print("B")
 elif marks >= 50:    
 print("C")
 else:    
 print("Fail")
```
