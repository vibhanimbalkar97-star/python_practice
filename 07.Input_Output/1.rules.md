## 2. Important Rule: input() Always Returns a String

This is one of the most important Python interview concepts.

```
age = input("Enter your age: ")print(age)print(type(age))
```

Input:

```
25
```

Output:

```
25
<class 'str'>
```

Even though the user enters `25`, Python treats it as a string `"25"`.

### Why?

Because `input()` reads everything entered by the user as text.

| User enters | Python receives |
| ----------- | --------------- |
| `10`        | `"10"`          |
| `25.5`      | `"25.5"`        |
| `True`      | `"True"`        |
| `hello`     | `"hello"`       |

### Interview question

What is the output?

```
a = input()b = input()print(a + b)
```

Input:

```
10
20
```

Output:

```
1020
```

Why? Because both values are strings, and `+` joins strings.
