## 4. Multiple Inputs in One Line

Python provides `split()` to separate input values.

### Example

```
a, b = input().split()
print(a)
print(b)
```

Input:

```
Hello Python
```

Output:

```
Hello
Python
```

### How split() works

```
text = "Hello Python World"
print(text.split())
```

Output:

```
['Hello', 'Python', 'World']
```

By default, `split()` separates text using whitespace (spaces, tabs, newlines).

### Important rule

Values received through `split()` are still strings.

```
a, b = input().split()
print(type(a))
print(type(b))
```

Input:

```
10 20
```

Output:

```
<class 'str'>
<class 'str'>
```

## 5. Taking Multiple Integer Inputs

Use `map()` with `split()`.

### Syntax

```
a, b = map(int, input().split())
```

### Example

```
a, b = map(int, input().split())
print(a + b)
```

Input:

```
10 20
```

Output:

```
30
```

### Understand each function

```
input()          # "10 20"
.split()         # ["10", "20"]
map(int, ...)    # converts each value to int
```

### Three numbers

```
a, b, c = map(int, input().split())
print(a + b + c)
```

Input:

```
10 20 30
```

Output:

```
60
```

### Float values

```
a, b = map(float, input().split())
print(a + b)
```

Input:

```
10.5 20.5
```

Output:

```
31.0
```

## 6. What is Output in Python?

Python uses the `print()` function to display output.

### Syntax

```
print(value)
```

Example:

```
name = "Vibha"
age = 25
print(name)
print(age)
```

Output:

```
Vibha
25
```

`print()` can display strings, numbers, variables, lists, and many other objects.

## 7. print() with Multiple Values

```
a = 10
b = 20
print(a, b)
```

Output:

```
10 20
```

By default, `print()` separates multiple values with a space.

### Using `sep`

`sep` means separator.

```
print(10, 20, 30, sep="-")
```

Output:

```
10-20-30
```

More examples:

```
print("Python", "JavaScript", sep=" | ")
print(1, 2, 3, sep=",")
print("A", "B", "C", sep="")
```

Output:

```
Python | JavaScript
1,2,3
ABC
```

## 8. print() with `end`

By default, `print()` adds a newline at the end.

```
print("Hello")
print("Python")
```

Output:

```
Hello
Python
```

### Using end

```
print("Hello", end=" ")
print("Python")
```

Output:

```
Hello Python
```

### More examples

```
print("A", end="-")
print("B", end="-")
print("C")
```

Output:

```
A-B-C
```

### Important difference

| Parameter | Purpose                   | Default |
| --------- | ------------------------- | ------- |
| `sep`     | Separates multiple values | `" "`   |
| `end`     | Adds something at the end | `"\n"`  |
