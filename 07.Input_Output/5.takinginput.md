## 11. Taking List Input

This is very important for coding interviews and HackerRank.

### A. Input as a list of strings

```
items = input().split()
print(items)
```

Input:

```
apple mango banana
```

Output:

```
['apple', 'mango', 'banana']
```

### B. Input as a list of integers

```
numbers = list(map(int, input().split()))
print(numbers)
```

Input:

```
10 20 30 40
```

Output:

```
[10, 20, 30, 40]
```

### C. Find the sum of list values

```
numbers = list(map(int, input().split()))
print(sum(numbers))
```

Input:

```
10 20 30
```

Output:

```
60
```

### D. Find maximum and minimum

```
numbers = list(map(int, input().split()))
print(max(numbers))
print(min(numbers))
```

Input:

```
5 10 2 20
```

Output:

```
20
2
```

## 12. Taking Input with a Specific Separator

By default, `split()` separates using whitespace.

You can also provide a separator.

```
a, b, c = input().split(",")
print(a)
print(b)
print(c)
```

Input:

```
10,20,30
```

Output:

```
10
20
30
```

But remember: values are strings.

For integer conversion:

```
a, b, c = map(int, input().split(","))
print(a + b + c)
```

Output:

```
60
```

## 13. Taking Input Using a Loop

When you need to take multiple inputs one by one, use a loop.

### Example: Take 3 numbers

```
for i in range(3):    
num = int(input("Enter number: "))    
print(num)
```

Input:

```
10
20
30
```

Output:

```
10
20
30
```

### Calculate the sum

```

```

Input:

```
10
20

```

Output:

```

```

## 14. Taking Input Until the User Stops

Use a `while` loop when you don't know how many inputs the user will enter.

```
while True:   
value = input("Enter q to quit: ")  

if value == "q":        
break   
print(value)
```

Example:

```
Enter q to quit: Hello
Hello
Enter q to quit: Python
Python
Enter q to quit: q
```

`break` stops the loop.
