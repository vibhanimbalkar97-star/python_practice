## 15. Important Input Errors

### A. ValueError

```
age = int(input())
```

Input:

```
hello
```

Error:

```
ValueError
```

Why? Python cannot convert `"hello"` into an integer.

### B. Too many values to unpack

```
a, b = input().split()
```

Input:

```
10 20 30
```

Error:

```
ValueError: too many values to unpack
```

Why? There are three values, but only two variables.

### C. Not enough values to unpack

```
a, b, c = input().split()
```

Input:

```
10 20
```

Error:

```
ValueError: not enough values to unpack
```

Why? Three variables need three values.

### D. Handle invalid input using try-except

```
try:    age = int(input("Enter age: "))    
print(age)except ValueError:    
print("Please enter a valid integer.")
```

Input:

```
hello
```

Output:

```
Please enter a valid integer.
```

## 16. `print()` Does Not Change the Original Data

```
a = 10print(a)
print(type(a))
```

Output:

```
10
<class 'int'>
```

`print()` only displays the value. It does not convert or modify the variable.

Example:

```
a = "10"print(int(a))
print(type(a))
```

Output:

```
10
<class 'str'>
```

Why? `int(a)` creates an integer value for printing, but the original variable `a` is still a string.

If you want to change the variable:

```
a = int(a)
print(type(a))
```

Output:

```
<class 'int'>
