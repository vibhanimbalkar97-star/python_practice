## 3. Type Conversion with input()

When you want to perform mathematical operations, convert the input into the required data type.

### A. Convert to Integer – `int()`

```
age = int(input("Enter age: "))
print(age + 5)
```

Input:

```
25
```

Output:

```
30
```

Explanation:

```
input()       # "25" → string
int("25")     # 25 → integer
```

### B. Convert to Float – `float()`

```
price = float(input("Enter price: "))
print(price + 10)
```

Input:

```
99.5
```

Output:

```
109.5
```

### C. Convert to Boolean – `bool()`

Be careful! `bool()` does not interpret the text `"False"` as Boolean False.

```
a = bool(input())
b = bool(input())
print(a)print(b)
```

Input:

```
False
0
```

Output:

```
True
True
```

Why?

Both `"False"` and `"0"` are non-empty strings.

Rule:

```
bool("")       # False
bool("False")  # True
bool("0")      # True
bool(" ")      # True
```

Only an empty string is false among these string examples.
