## 9. Formatted Output – f-strings

f-strings are the easiest and most common way to display variables inside strings.

### Example

```
name = "Vibha"
age = 25
print(f"My name is {name} and I am {age} years old.")
```

Output:

```
My name is Vibha and I am 25 years old.
```

### Why use f-strings?

Instead of:

```
print("My age is", age)
```

You can write:

```
print(f"My age is {age}")
```

### Perform calculations inside f-strings

```
a = 10b = 20
print(f"Sum = {a + b}")
```

Output:

```
Sum = 30
```

### Formatting decimal values

```
price = 99.5678
print(f"{price:.2f}")
```

Output:

```
99.57
```

`.2f` means display two digits after the decimal point.

```
print(f"{price:.1f}")  # 99.6
print(f"{price:.3f}")  # 99.568
```

## 10. Other Ways of Formatting Output

### A. Using `format()`

```
name = "Vibha"
age = 25
print("My name is {} and my age is {}".format(name, age))
```

Output:

```
My name is Vibha and my age is 25
```

### B. Using `%` formatting

```
name = "Vibha"
age = 25
print("My name is %s and my age is %d" % (name, age))
```

Output:

```
My name is Vibha and my age is 25
```

| Symbol | Meaning |
| ------ | ------- |
| `%s`   | String  |
| `%d`   | Integer |
| `%f`   | Float   |

Interview point: f-strings are generally preferred in modern Python because they are readable and convenient.
