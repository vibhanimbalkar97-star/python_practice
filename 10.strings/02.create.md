## 2. Creating strings

```
s1 = "Hello"
s2 = 'Hello'
s3 = """HelloPythonWorld"""
print(s3)
```

Output:

```
Hello
Python
World
```

Triple quotes allow multiline strings.

### Quotes inside strings

```
print("It's Python")
print('He said "Hello"')
print("It\'s Python")
```

Use different outer and inner quotes, or escape a quote with `\`.
