## 11. Replacing characters or words – `replace()`

Syntax:

```
string.replace(old, new, count)
```

- `old`: text to replace.
- `new`: replacement text.
- `count`: optional maximum number of replacements.

```
s = "banana"
print(s.replace("a", "o"))     # bonono
print(s.replace("a", "o", 1))  # bonana
print(s.replace("a", ""))      # bnn
```

Replace words:

```
s = "I love Java"
print(s.replace("Java", "Python"))
# I love Python
```

Trick: `replace()` does not modify the original string.

```
s = "hello"
s.replace("h", "H")
print(s)  # hello
```
