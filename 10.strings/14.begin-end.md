## 14. Checking the beginning and ending

```
s = "Python Programming"
print(s.startswith("Python"))  # True
print(s.startswith("Java"))    # False
print(s.endswith("Programming"))  # True
print(s.endswith("Python"))       # False
```

You can pass a tuple of possible prefixes or suffixes:

```
filename = "photo.png"
print(filename.endswith((".png", ".jpg", ".jpeg")))
# True
```

Useful for file extensions and input validation.
