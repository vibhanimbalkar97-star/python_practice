## 19. Escape characters

Escape characters are special sequences that represent characters inside a string.

| Escape | Meaning      | Example            |
| ------ | ------------ | ------------------ |
| `\n`   | New line     | `"Hello\nWorld"`   |
| `\t`   | Tab          | `"Hello\tWorld"`   |
| `\\`   | Backslash    | `"C:\\Users"`      |
| `\'`   | Single quote | `'It\'s Python'`   |
| `\"`   | Double quote | `"He said \"Hi\""` |

```
print("Hello\nWorld")
```

Output:

```
Hello
World
```
