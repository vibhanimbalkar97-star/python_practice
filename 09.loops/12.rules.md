# 15. Important Loop Logic for Coding Questions

These are common beginner coding problems. Learn the logic, not just the output.

## A. Print even numbers

```
for i in range(1, 11):    if i % 2 == 0:        print(i)
```

Output:

```
2
4
6
8
10
```

Trick: Even numbers have remainder 0 when divided by 2.

## B. Print odd numbers

```
for i in range(1, 11):    if i % 2 != 0:        print(i)
```

Output:

```
1
3
5
7
9
```

## C. Sum of numbers

```
total = 0for i in range(1, 6):    total += iprint(total)
```

Output:

```

```

## D. Factorial

Factorial of 5:

\\[ 5! = 5 \times 4 \times 3 \times 2 \times 1 = 120 \\]

```
num = 5factorial = 1for i in range(1, num + 1):    factorial *= iprint(factorial)
```

Output:

```
120
```

Trick: Initialize factorial with `1`, not `0`. Multiplying by zero would always produce zero.

## E. Reverse a number

```
num = 1234reverse = 0while num > 0:    digit = num % 10    reverse = reverse * 10 + digit    num //= 10print(reverse)
```

Output:

```
4321
```

Logic:

| Step | `num` | `digit` | `reverse` |
| ---- | ----- | ------- | --------- |
| 1    | 1234  | 4       | 4         |
| 2    | 123   | 3       | 43        |
| 3    | 12    | 2       | 432       |
| 4    | 1     | 1       | 4321      |
| 5    | 0     | —       | Stop      |

## F. Count digits

```
num = 12345count = 0while num > 0:    count += 1    num //= 10print(count)
```

Output:

```
5
```

Note: This version is intended for positive integers. `0` and negative numbers need additional handling.
