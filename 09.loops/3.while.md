# 3. Python `while` Loop

A `while` loop repeats as long as the condition is `True`.

### Syntax

```
while condition:    # code
```

### Example

```
i = 1
while i <= 5:    
print(i)    
i += 1
```

Output:

```
1
2
3
4
5
```

### Step-by-step dry run

| Step | `i` | Condition `i <= 5` | Output | Update  |
| ---- | --- | ------------------ | ------ | ------- |
| 1    | 1   | True               | 1      | `i = 2` |
| 2    | 2   | True               | 2      | `i = 3` |
| 3    | 3   | True               | 3      | `i = 4` |
| 4    | 4   | True               | 4      | `i = 5` |
| 5    | 5   | True               | 5      | `i = 6` |
| 6    | 6   | False              | Stop   | —       |

### Three important rules

1. Condition is checked before the body.
2. If condition is initially false, body executes zero times.
3. Update the variable when needed to avoid an infinite loop.

### Tricky Example 1: No execution

```
i = 10
while i < 5:    
print(i)
```

Output: No output.

### Tricky Example 2: Infinite loop

```
i = 1
while i <= 3:    
print(i)
```

Output:

```
1
1
1
1
...
```

Why? `i` never changes.

### Tricky Example 3: Update before printing

```
i = 1

while i <= 3:    
i += 1    
print(i)


```

Output:

```
2
3
4
```

Trick: Always check whether the update happens before or after `print()`.
