# 5. Nested Loops in Python

Nested loop = one loop inside another loop.

```
for i in range(1, 3):    
for j in range(1, 4):        
print(i, j)
```

Output:

```
1 1
1 2
1 3
2 1
2 2
2 3
```

### How to understand it

- Outer loop: `i`
- Inner loop: `j`
- Inner loop runs completely for every outer iteration.
- Inner loop starts again from its initial value for each outer iteration.

### Dry Run Table

| Outer `i` | Inner `j` values | Output count |
| --------- | ---------------- | ------------ |
| 1         | 1, 2, 3          | 3            |
| 2         | 1, 2, 3          | 3            |

Total output:

\\[ 2 \times 3 = 6 \\]

## Tricky Example 1: Inner loop depends on outer loop

```
for i in range(1, 4):    
for j in range(1, i + 1):        
print(i, j)
```

Output:

```
1 1
2 1
2 2
3 1
3 2
3 3
```

Why?

Python's `range()` excludes the stop value, so `range(1, i + 1)` includes values up to `i`.

## Tricky Example 2: Pattern printing

```
for i in range(1, 5):    
for j in range(i):        
print("*", end="")    
print()
```

Output:

```
*
**
***
****
```

### How this works

- `print("*", end="")` prints stars on the same line.
- `print()` moves to the next line.
- Outer loop controls rows.
- Inner loop controls stars in each row.

## Tricky Example 3: Reverse pattern

```
for i in range(4, 0, -1):    
for j in range(i):        
print("*", end="")    
print()
```

Output:

```
****
***
**
*
```

## Tricky Example 4: `break` inside nested loops

```
for i in range(1, 4):    
for j in range(1, 4):        
if j == 2:           
 break        
 print(i, j)
```

Output:

```
1 1
2 1
3 1
```

`break` stops only the inner loop.
