# 2. Python `range()` Function

`range()` generates a sequence of numbers.

It is one of the most important concepts in Python loops.

## Three forms of `range()`

| Syntax                     | Meaning                              |
| -------------------------- | ------------------------------------ |
| `range(stop)`              | Start from 0                         |
| `range(start, stop)`       | Start from given value               |
| `range(start, stop, step)` | Start, stop, and increment/decrement |

### Rule: Stop is excluded

```
for i in range(1, 5):    print(i)
```

Output:

```
1
2
3
4
```

`5` is not included.

### Example 1: `range(stop)`

```
for i in range(5):    print(i)
```

Output:

```
0
1
2
3
4
```

### Example 2: `range(start, stop)`

```
for i in range(2, 6):    print(i)
```

Output:

```
2
3
4
5
```

### Example 3: `range(start, stop, step)`

```
for i in range(1, 10, 2):    print(i)
```

Output:

```
1
3
5
7
9
```

Here, step is 2.

### Example 4: Decrement

```
for i in range(5, 0, -1):    print(i)
```

Output:

```
5
4
3
2
1
```

### Important trick

```
for i in range(5, 1, -1):    print(i)
```

Output:

```
5
4
3
2
```

`1` is excluded.

## How to calculate range values

Formula:

\\[ \text{Next value} = \text{Current value} + \text{Step} \\]

Example:

```
range(2, 10, 3)
```

Values:

```
2 → 5 → 8
```

Next value = 11, which is beyond the stop value.

## Tricky range examples

### Example 1

```
print(list(range(1, 5)))
```

Output:

```
[1, 2, 3, 4]
```

### Example 2

```
print(list(range(5, 1)))
```

Output:

```
[]
```

Why? Default step is `+1`, but starting value is already greater than stop.

### Example 3

```
print(list(range(5, 1, -1)))
```

Output:

```
[5, 4, 3, 2]
```

### Example 4

```
print(list(range(1, 10, 0)))
```

Output:

```
ValueError: range() arg 3 must not be zero
```

Step cannot be zero.

### Example 5

```
for i in range(1, 4):    print(i * 2)
```

Output:

```
2
4
6
```
