# 13. Loop Variables and Scope

## Example 1: Variable remains after loop

```
for i in range(3):    
print(i)
print(i)
```

Output:

```
0
1
2
2
```

Unlike JavaScript `let`, Python's `for` loop variable is not limited to a separate loop block.

## Example 2: Empty loop

```
for i in range(0):    print(i)print("Done")
```

Output:

```
Done
```

The loop doesn't run, so `i` is never assigned by the loop.

If `i` had already been defined earlier, its previous value would remain.

## Example 3: Nested loop variables

```
for i in range(1, 3):    
    for j in range(1, 3):        
    print(i, j)
print(i, j)
```

Output:

```
1 1
1 2
2 1
2 2
2 2
```

After the loops, the last assigned values remain.
