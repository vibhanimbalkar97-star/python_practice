# 12. `iter()` and `next()` – How a Loop Works Internally

This is useful to understand what happens behind a `for` loop.

Python uses an iterator to fetch items one by one.

### Example

```
numbers = [10, 20, 30]

it = iter(numbers)
print(next(it))
print(next(it))
print(next(it))
```

Output:

```
10
20
30
```

If you call `next()` again:

```
print(next(it))
```

Output:

```
StopIteration
```

More precisely, Python raises a `StopIteration` exception.

### How `for` works conceptually

```
for num in numbers:    print(num)
```

Conceptually:

1. Python gets an iterator.
2. Calls `next()` to get the next value.
3. Executes the body.
4. Repeats until `StopIteration`.
5. Ends the loop.

You don't normally need to use `iter()` and `next()` directly, but they explain how Python loops work.
