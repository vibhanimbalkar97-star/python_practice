# 14. Tricky Python Loop Examples

These examples are important for output-based interview questions.

## Example 1: `else` with empty loop

```
for i in range(0):    
print(i)else:    
print("Finished")
```

Output:

```
Finished
```

Why? The loop completed normally, even though it ran zero times.

## Example 2: `continue` in a `while` loop

```
i = 0
while i < 5:    
i += 1    
if i == 3:        
continue    
print(i)
```

Output:

```
1
2
4
5
```

Why? `i` is updated before `continue`, so the loop does not get stuck.

## Example 3: Nested loop with same variable name

```
for i in range(1, 3):    
for i in range(1, 3):        
print(i)
```

Output:

```
1
2
1
2
```

The inner loop reassigns `i`. Python does not create a separate block-scoped `i` for the inner loop.

## Example 4: Changing list during iteration

```
numbers = [1, 2, 3]

for num in numbers:    
numbers.append(num)    
if len(numbers) > 5:        
break
print(numbers)
```

Output:

```
[1, 2, 3, 1, 2, 3]
```

Appending while iterating can cause confusing behavior. Avoid it unless you intentionally need that behavior.

## Example 5: Loop over boolean values

```
for i in range(3):    
print(bool(i))
```

Output:

```
False
True
True
```

Why?

- `bool(0)` → `False`
- `bool(1)` → `True`
- `bool(2)` → `True`

## Example 6: Accumulating a sum

```
total = 0

for i in range(1, 5):    
total += i
print(total)
```

Output:

```
10
```

Calculation:

```
total = 0 + 1 = 1
total = 1 + 2 = 3
total = 3 + 3 = 6
total = 6 + 4 = 10
```

## Example 7: Multiplication

```
for i in range(1, 4):    
print(i * 2)
```

Output:

```
2
4
6
```

## Example 8: Nested loop with `break`

```
for i in range(1, 4):    
for j in range(1, 4):        
if i + j == 4:            
break        
print(i, j)
```

Output:

```
1 1
1 2
2 1
```

When the inner loop reaches `i + j == 4`, it stops. The outer loop continues.
