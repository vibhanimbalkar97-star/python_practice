# 6. Looping Through Python Collections

Python loops work with different data types.

## A. List

```
numbers = [10, 20, 30]
for num in numbers:    
print(num)
```

Output:

```
10
20
30
```

### Tricky: Modifying list during iteration

```
numbers = [1, 2, 3, 4]
for num in numbers:    
numbers.remove(num)
print(numbers)
```

Output:

```
[2, 4]
```

Why? The list is changing while Python iterates over it, so some elements are skipped.

Best practice: Avoid modifying a list while iterating over it. Use a new list or iterate over a copy.

```
numbers = [1, 2, 3, 4]
for num in numbers[:]:    
numbers.remove(num)
print(numbers)
```

Output:

```
[]
```

## B. Tuple

```
numbers = (10, 20, 30)
for num in numbers:    
print(num)
```

Output:

```
10
20
30
```

## C. Set

```
numbers = {10, 20, 30}
for num in numbers:    
print(num)
```

The values are iterated, but don't rely on a particular order.

## D. Dictionary

```
student = {    "name": "Amit",    "age": 22,    "city": "Pune"}
```

### Loop through keys

```
for key in student:    
print(key)
```

Output:

```
name
age
city
```

### Loop through values

```
for value in student.values():    
print(value)
```

Output:

```
Amit
22
Pune
```

### Loop through keys and values

```
for key, value in student.items():    
print(key, value)
```

Output:

```
name Amit
age 22
city Pune
```

### Tricky dictionary example

```
student = {"a": 1, "b": 2}
for key in student:    
print(key, student[key])
```

Output:

``
a 1
b 2
```

Remember:

- `student` → keys
- `student.keys()` → keys
- `student.values()` → values
- `student.items()` → key-value pairs
