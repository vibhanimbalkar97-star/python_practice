# 4. `break`, `continue`, and `pass`

These three statements are important in interviews.

## A. `break`

`break` stops the loop immediately.

```
for i in range(1, 6):    if i == 3:        break    print(i)
```

Output:

```
1
2
```

When `i == 3`, the loop ends.

### Tricky example

```
for i in range(1, 6):    print(i)    if i == 3:        break
```

Output:

```
1
2
3
```

Position matters!

## B. `continue`

`continue` skips the current iteration.

```
for i in range(1, 6):    if i == 3:        continue    print(i)
```

Output:

```
1
2
4
5
```

### Tricky example

```
for i in range(5):    if i == 2:        continue    print(i)
```

Output:

```
0
1
3
4
```

## C. `pass`

`pass` does nothing. It is used as a placeholder.

```
for i in range(1, 4):    passprint("Done")
```

Output:

```
Done
```

### Difference table

| Statement  | Meaning    | Loop behavior           |
| ---------- | ---------- | ----------------------- |
| `break`    | Stop       | Ends the loop           |
| `continue` | Skip       | Goes to next iteration  |
| `pass`     | Do nothing | Loop continues normally |

### Interview trick

```
for i in range(1, 5):    
if i == 2:        
pass    
print(i)
```

Output:

```
1
2
3
4
```

`pass` does not skip 2. It simply does nothing.
