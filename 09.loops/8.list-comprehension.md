# 10. List Comprehension

List comprehension is a shorter way to create a list using a loop.

### Normal loop

```
numbers = []

for i in range(1, 6):    
numbers.append(i)print(numbers)
```

Output:

```
[1, 2, 3, 4, 5]
```

### List comprehension

```
numbers = [i for i in range(1, 6)]
print(numbers)
```

Output:

```
[1, 2, 3, 4, 5]
```

### Syntax

```
[expression for item in iterable]
```

## Example 1: Square numbers

```
squares = [i ** 2 for i in range(1, 6)]
print(squares)
```

Output:

```
[1, 4, 9, 16, 25]
```

## Example 2: With condition

```
even_numbers = [i for i in range(1, 11) if i % 2 == 0]
print(even_numbers)
```

Output:

```
[2, 4, 6, 8, 10]
```

### Syntax with condition

```
[expression for item in iterable if condition]
```

## Example 3: If-else in comprehension

```
result = ["Even" if i % 2 == 0 else "Odd" for i in range(1, 6)]
print(result)
```

Output:

```
['Odd', 'Even', 'Odd', 'Even', 'Odd']
```

### Important difference

Condition for filtering:

```
[i for i in range(5) if i > 2]
```

Output:

```
[3, 4]
```

Conditional expression:

```
["Yes" if i > 2 else "No" for i in range(5)]
```

Output:

```
['No', 'No', 'No', 'Yes', 'Yes']
```

The first removes items. The second chooses a value for each item.
