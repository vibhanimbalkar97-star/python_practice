# 7. `else` With Loops

Python has a special feature: `else` can be used with both `for` and `while`.

The `else` block executes when the loop completes normally, without being stopped by `break`.

## Example 1: `for...else`

```
for i in range(1, 4):    
print(i)
else:    
print("Loop completed")
```

Output:

```
1
2
3
Loop completed
```

## Example 2: `break` skips `else`

```
for i in range(1, 5):    
if i == 3:        
break    
print(i)
else:    
print("Loop completed")
```

Output:

```
1
2
```

The `else` block doesn't execute because `break` stopped the loop.

## Example 3: `continue` does not skip `else`

```
for i in range(1, 4):    
if i == 2:        
continue    
print(i)else:    
print("Completed")
```

Output:

```
1
3
Completed
```

### Important rule

| Situation                | Loop `else` executes?             |
| ------------------------ | --------------------------------- |
| Loop completes normally  | Yes                               |
| Loop has zero iterations | Yes                               |
| `break` occurs           | No                                |
| `continue` occurs        | Yes                               |
| `return` exits function  | No, execution leaves the function |

## Interview example: Prime number check

```
num = 7
for i in range(2, num):    
if num % i == 0:        
print("Not prime")        
break
else:    
print("Prime")
```

Output:

```
Prime
```

Why?

- The loop checks if any number divides 7.
- No divisor is found.
- Loop completes without `break`.
- `else` executes.

# 8. `enumerate()` – Get Index and Value

When using a `for` loop, sometimes you need both the index and the value.

### Without enumerate

```
fruits = ["apple", "mango", "banana"]
for i in range(len(fruits)):    
print(i, fruits[i])
```

Output:

```
0 apple
1 mango
2 banana
```

### With enumerate

```
fruits = ["apple", "mango", "banana"]
for index, fruit in enumerate(fruits):    
print(index, fruit)
```

Output:

```
0 apple
1 mango
2 banana
```

### Start index from 1

```
for index, fruit in enumerate(fruits, start=1):    
print(index, fruit)
```

Output:

```
1 apple
2 mango
3 banana
```

### Tricky example

```
names = ["A", "B", "C"]
for index, name in enumerate(names):    
print(index + 1, name)
```

Output:

```
1 A
2 B
3 C
```

Remember: `enumerate()` returns pairs of index and value.

# 9. `zip()` – Loop Through Two Lists Together

`zip()` combines elements from multiple iterables position by position.

### Example

```
names = ["Amit", "Neha", "Raj"]
marks = [80, 90, 70]
for name, mark in zip(names, marks):    
print(name, mark)
```

Output:

```
Amit 80
Neha 90
Raj 70
```

### Tricky example: Different lengths

```
names = ["Amit", "Neha", "Raj"]
marks = [80, 90]
for name, mark in zip(names, marks):    
print(name, mark)
```

Output:

```
Amit 80
Neha 90
```

`zip()` stops when the shortest iterable ends.

### Example: Three lists

```
names = ["Amit", "Neha"]
marks = [80, 90]
cities = ["Pune", "Mumbai"]
for name, mark, city in zip(names, marks, cities):    
print(name, mark, city)
```

Output:

```
Amit 80 Pune
Neha 90 Mumbai
