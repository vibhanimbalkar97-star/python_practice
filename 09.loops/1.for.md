# 1. Python `for` Loop

A `for` loop is used to iterate over a sequence or iterable.

### Syntax

```
for variable in iterable:    # code
```

Example:

```
fruits = ["apple", "mango", "banana"]for fruit in fruits:    print(fruit)
```

Output:

```
apple
mango
banana
```

### How it works

- Python takes the first item from the list.
- Assigns it to `fruit`.
- Executes the loop body.
- Takes the next item.
- Stops when no items remain.

Unlike JavaScript, Python's `for` loop does not require initialization, condition, and update sections.

## Example: Print numbers

```
for i in [1, 2, 3, 4, 5]:    print(i)
```

Output:

```
1
2
3
4
5
```

## Tricky Example 1: Loop over a string

```
name = "Python"for char in name:    print(char)
```

Output:

```
P
y
t
h
o
n
```

Each iteration gives one character.

## Tricky Example 2: Loop over a list

```
numbers = [10, 20, 30]for num in numbers:    print(num + 5)
```

Output:

```
15
25
35
```

Remember: `num` takes the value of each element one by one.
