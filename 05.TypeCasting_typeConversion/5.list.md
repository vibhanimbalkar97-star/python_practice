# 7. Rules of list(), tuple(), set()

These are used to convert iterable objects into collections.

An iterable means something you can loop through, like a string, list, tuple, or range.

### Rule 1: String to list

```
print(list("Python"))
```

Output:

```
['P', 'y', 't', 'h', 'o', 'n']
```

Why? A string is iterable, so Python takes each character separately.

### Rule 2: String to tuple

```
print(tuple("ABC"))
```

Output:

```
('A', 'B', 'C')
```

### Rule 3: String to set

```
print(set("hello"))
```

Output (order may vary):

```
{'h', 'e', 'l', 'o'}
```

Why? Set stores only unique elements. Duplicate `l` is removed.

### Rule 4: List to tuple

```
print(tuple([1, 2, 3]))# (1, 2, 3)
```

### Rule 5: Tuple to list

```
print(list((1, 2, 3)))# [1, 2, 3]
```

### Rule 6: List to set removes duplicates

```
print(set([1, 2, 2, 3, 3]))# {1, 2, 3}
```

Why? Sets only store unique elements.

### Rule 7: Set to list

```
print(list({1, 2, 3}))# [1, 2, 3]
```

Remember: Set does not guarantee insertion order. Do not rely on the resulting list order.

### Rule 8: Dictionary to list

```
data = {"a": 10, "b": 20}
print(list(data))# ['a', 'b']
```

Why? Iterating over a dictionary directly gives its keys.

### Rule 9: Dictionary to tuple

```
data = {"a": 10, "b": 20}
print(tuple(data))# ('a', 'b')
```

### Rule 10: Dictionary to set

```
data = {"a": 10, "b": 20}
print(set(data))# {'a', 'b'}
```

### Rule 11: Range to list

```
print(list(range(1, 5)))# [1, 2, 3, 4]
```

### Rule 12: Integer directly to list is invalid

```
print(list(123))
```

Output: `TypeError`

Why? Integer is not iterable.

Correct:

```
print(list(str(123)))# ['1', '2', '3']
```
