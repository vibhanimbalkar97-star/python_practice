# 14. Final Interview Revision Checklist

Use this as your quick revision sheet before interviews.

| Rule              | Remember                |
| ----------------- | ----------------------- |
| `input()`         | Always returns string   |
| `int(10.9)`       | Returns 10, not 11      |
| `int(-10.9)`      | Returns -10             |
| `int("10.5")`     | ValueError              |
| `float("10")`     | Returns 10.0            |
| `str(False)`      | Returns `"False"`       |
| `bool("False")`   | Returns True            |
| `bool("0")`       | Returns True            |
| `bool("")`        | Returns False           |
| `bool(" ")`       | Returns True            |
| `bool([])`        | Returns False           |
| `bool([0])`       | Returns True            |
| `bool(None)`      | Returns False           |
| `True + 1`        | Returns 2               |
| `10 / 2`          | Returns 5.0             |
| `10 // 3`         | Returns 3               |
| `-10 // 3`        | Returns -4              |
| `"Hi" * 3`        | Returns `"HiHiHi"`      |
| `10 + "20"`       | TypeError               |
| `list("abc")`     | Returns `['a','b','c']` |
| `set([1,1,2])`    | Removes duplicates      |
| `dict([("a",1)])` | Creates dictionary      |

Q1. What is the output?

print(int(12.99))

12

13

12.99

ValueError

Correct

int() truncates the decimal part towards zero.

Q2. What is the output?

print(bool("False"))

False

True

ValueError

None

Correct

A non-empty string is always truthy.

Q3. What is the output?

print(True + False + 5)

5

6

1

TypeError

Correct

True is 1 and False is 0. So 1 + 0 + 5 = 6.

Q4. What happens?

print(int("10.5"))

10

10.5

ValueError

TypeError

Correct

A decimal string cannot be directly converted to int.

Q5. What is the output?

print(bool([0, False, None]))

False

True

None

TypeError

Correct

The list is non-empty, so it is truthy.

Q6. What is the output?

510

5510

1010

TypeError

Correct

"5" \* 2 gives "55"; adding "10" gives "5510".

Q7. What is the output?

int() truncates towards zero.

Q8. What is the output?

Q9. What is the output?

Converting a dictionary to a list returns its keys.

Q10. What is the output?
