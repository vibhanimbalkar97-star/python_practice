### Important explanations

Q1 — `+` and `-` behave differently

```
console.log("10" + 5); // "105"
console.log("10" - 5); // 5
```

- `+` with a string performs concatenation.
- `-` converts the string to a number.

Q4 — `NaN` is still a number type

```
typeof NaN; // "number"
NaN === NaN; // false
```

Q5 — `null` and `undefined` conversion

```
Number(null);      // 0
Number(undefined); // NaN
String(null);      // "null"
```

These do not throw errors.

Q7 — Array conversion

```
String([1, 2, 3]); // "1,2,3"
Number([]);        // 0
Number([5]);       // 5
Number([1, 2]);    // NaN
```

An array containing one numeric value can convert to that number. An array with multiple values cannot convert to one number.

Q8 — Evaluation happens left to right

```
let a = 1;
let b = "2";
let c = 3;

console.log(a + b + c); // "123"
console.log(a + c + b); // "42"
```

- First: `1 + "2"` → `"12"`; then `"12" + 3` → `"123"`
- Second: `1 + 3` → `4`; then `4 + "2"` → `"42"`

Q10 — `parseInt()` vs `Number()`

```
parseInt("12.8"); // 12
Number("12.8");   // 12.8
parseInt("12px"); // 12
Number("12px");   // NaN
```

`parseInt()` reads the integer part from the beginning. `Number()` tries to convert the entire string.

### Important explanations

Q1 — Python does not automatically concatenate a string and integer

```
print("10" + 5)  # TypeErrorprint("10" * 2)  # 1010
```

- `"10" + 5` → `TypeError`: string and integer cannot be added.
- `"10" * 2` → `"1010"`: strings can be repeated using `*`.

Q6 — A set removes duplicates

```
print(list({1, 2, 2, 3}))
```

Output:

```
[1, 2, 3]
```

A set keeps only unique values. Its order is not guaranteed.

Q9 — `==` compares values; `is` compares identity

```
a = 10b = 10.0print(a == b)          # Trueprint(a is b)          # Falseprint(type(a) == type(b)) # False
```

- `10 == 10.0` → `True`, because their numeric values are equal.
- `a is b` → `False`, because they are not the same object.
- Their types are different: `int` and `float`.
