# 5. Rules of str()

`str()` converts almost every Python object into its string representation.

### Rule 1: Integer to string

```
a = str(100)
print(a)        # "100"
print(type(a))  # str
```

### Rule 2: Float to string

```
print(str(10.5))  # "10.5"
```

### Rule 3: Boolean to string

```
print(str(True))   # "True"
print(str(False))  # "False"
```

Important: These are strings, not Boolean values.

```
a = str(False)
print(bool(a))  # True
```

Why? `"False"` is a non-empty string.

### Rule 4: List to string

```
a = [1, 2, 3]
print(str(a))  # "[1, 2, 3]"
print(type(str(a)))  # str
```

Important: `str(list)` does not convert the list elements individually into a new list of strings. It converts the whole list representation into one string.

### Rule 5: None to string

```
print(str(None))  # "None"
```

It is a string, not the `None` object.
