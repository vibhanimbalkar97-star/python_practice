# 4. Rules of float()

### Rule 1: Integer to float

```
print(float(10))  # 10.0
```

Why? Python adds a decimal representation.

### Rule 2: Integer string to float

```
print(float("100"))  # 100.0
```

### Rule 3: Decimal string to float

```
print(float("10.5"))  # 10.5
```

### Rule 4: Float to float

```
print(float(10.5))  # 10.5
```

### Rule 5: Boolean to float

```
print(float(True))   # 1.0
print(float(False))  # 0.0
```

### Rule 6: Spaces are allowed

```
print(float(" 10.5 "))  # 10.5
```

### Rule 7: Invalid numeric strings give ValueError

```
print(float("hello"))  # ValueError
print(float(""))       # ValueError
```

### Rule 8: Special float values

```
print(float("inf"))   # inf
print(float("-inf"))  # -inf
print(float("nan"))   # nan
```

Why? Python supports infinity and NaN (Not a Number) as floating-point values.
