# 6. Rules of bool() – Very Important for Interviews

Python follows the truthy and falsy concept.

Falsy values become False. Most other values become True.

### Rule 1: Numeric values

```
print(bool(0))      # False
print(bool(1))      # True
print(bool(-1))     # True
print(bool(100))    # True
print(bool(0.0))    # False
print(bool(-0.5))   # True
```

Why? Zero is falsy. Non-zero numbers are truthy.

### Rule 2: Strings

```
print(bool(""))       # False
print(bool(" "))      # True
print(bool("hello"))  # True
print(bool("0"))      # True
print(bool("False"))  # True
```

Interview rule

Empty string = False.

Non-empty string = True.

Even if it contains `"0"`, `"False"` or only spaces, it is True.

Why? Python checks whether the string is empty, not what the string means.

### Rule 3: Lists

```
print(bool([]))        # False
print(bool([1, 2]))    # True
print(bool([0]))       # True
print(bool([""]))      # True
```

Why? Empty collection = False. Non-empty collection = True.

### Rule 4: Tuples

```
print(bool(()))       # False
print(bool((0,)))     # True
print(bool((1, 2)))   # True
```

### Rule 5: Sets

```
print(bool(set()))       # False
print(bool({1, 2}))      # True
```

### Rule 6: Dictionaries

```
print(bool({}))             # False
print(bool({"a": 1}))       # True
```

### Rule 7: None

```
print(bool(None))  # False
```

Why? `None` represents the absence of a value.

### Rule 8: NaN

```
print(bool(float("nan")))  # True
```

Why? NaN is a floating-point value, not zero.

### Complete falsy values – Memorize these

| Value      | Boolean result |
| ---------- | -------------- |
| `False`    | False          |
| `None`     | False          |
| `0`        | False          |
| `0.0`      | False          |
| `0j`       | False          |
| `""`       | False          |
| `[]`       | False          |
| `()`       | False          |
| `{}`       | False          |
| `set()`    | False          |
| `range(0)` | False          |

Interview shortcut: Empty, zero, or None generally means False. Everything else is True, unless a custom object defines its own truth behavior.
