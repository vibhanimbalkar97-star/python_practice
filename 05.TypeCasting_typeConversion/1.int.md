# 3. Rules of int() – String to Integer

This is one of the most important interview areas.

### Rule 1: Integer string can be converted

```
print(int("100"))    # 100
print(int("-100"))   # -100
print(int("+100"))   # 100
```

Why? These strings contain valid integer representations.

### Rule 2: Decimal string cannot directly convert into int

```
print(int("10.5"))
```

Output:

```
ValueError
```

Why? `"10.5"` is a decimal string, not an integer string.

Correct:

```
print(int(float("10.5")))  # 10
```

### Rule 3: Float to int removes decimal part

```
print(int(10.9))   # 10
print(int(10.1))   # 10
print(int(-10.9))  # -10
```

Why? `int()` truncates towards zero. It does not round.

Compare:

```
print(int(10.9))   # 10
print(round(10.9)) # 11
```

### Rule 4: Boolean to int

```
print(int(True))   # 1
print(int(False))  # 0
```

Why? In Python, `bool` is a subclass of `int`.

### Rule 5: Empty string cannot convert into int

```
print(int(""))
```

Output: `ValueError`

Why? There is no numeric value to convert.

### Rule 6: Spaces around numeric strings are allowed

```
print(int("  100  "))  # 100
```

Why? Python ignores leading and trailing whitespace.

### Rule 7: Strings containing letters cannot convert

```
print(int("100abc"))  # ValueError
print(int("abc"))     # ValueError
```

Why? These are not valid integer representations.

### Rule 8: int() supports different number bases

```
print(int("1010", 2))  # 10
print(int("10", 8))    # 8
print(int("10", 16))   # 16
```

Why? The second argument specifies the base.

- Binary = 2
- Octal = 8
- Decimal = 10
- Hexadecimal = 16
